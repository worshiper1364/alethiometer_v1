# Laser Cutting

Symbol tiles were engraved on and cut out of 1/16" thick basswood using an Epilog Mini 40W CO2 laser cutter. I ended up using these settings, but you will need to test your own. Never leave a laser cutter unattended.

**Engrave**

* Speed: 70% speed
* Power: 95% power


**Cut**

* Speed: 48% speed
* Power: 98% power

The tiles fit perfectly into the symbol holder pockets, so I didn't need to use any glue. They are very hard to take out.

**`alethiometer_tiles_bold_and_standard.svg`**: This file contains two sets of symbols, one in bold and one not bold

**`alethiometer_tiles_material_test_subset.svg`**: This file contains a subset of symbols for testing

The symbols were generated with ChatGPT using written descriptions of the symbols.
